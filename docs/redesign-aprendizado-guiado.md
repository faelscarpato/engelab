# ENGELAB — Redesign de Aprendizado Guiado

## Versão
Refinamento visual e pedagógico focado em aprendizado guiado.

## Objetivo
Transformar a plataforma em um ambiente que conduz o aluno pela próxima ação, reduzindo ruído visual e mantendo o foco em estudo, produção conceitual, evidência e responsabilidade técnica.

## Entregas principais

- Landing page redesenhada.
- Dashboard interno com próxima ação recomendada.
- Trilha “Comece Aqui” estruturada como percurso de aprendizagem.
- Árvore de documentos com filtros, status e próximo documento recomendado.
- Página “Meus Materiais” reorganizada como mesa de estudos.
- Central de agentes simplificada por tarefa.
- Página de evolução orientada por metas.
- Sidebar reorganizada por contexto.
- Header com busca e perfil.
- Guia de mapa de calor visual incluído em `docs/visual-learning-heatmap.md`.

## Validação
Build executado com sucesso com `npm run build`.
